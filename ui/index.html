What all-the-jev is

About Jev: question types and request format

A visualizer for Jev that sits between your code and TypeSafe. Your requests come here instead of going to TypeSafe; all-the-jev sends each one on with your key, hands Jev's answer back, and keeps a copy to show you. It answers nothing itself.

Send Jev requests here

http://127.0.0.1:4777/v1/systemone

The same requests and answers as TypeSafe's address, with no key needed. To group requests under a project or label, add it to the path: /<label>/v1/systemone.

Link a call to the answer that led to it

Each answer comes back with an event id in events. Send it with a later call in a all-the-jev-Trigger header and the map grows that call off the answer. all-the-jev drops the header before calling Jev.

Show names, not keys

Answers are labelled with their option's key. When the criteria behind the keys are objects, send all-the-jev-Display: name and the map shows that part of each option instead; an option without it keeps its key.

Where calls are kept

all-the-jev stores calls, agent revisions, and reviews locally. Jev evaluations go to the configured System One endpoint; discussion sends selected evidence to OpenRouter only when you ask.

For agents and scripts: llms.txt explains how to connect.
